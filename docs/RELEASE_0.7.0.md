# إصدار 0.7.0

بناءً على طلب المستخدم، أزيلت الضبابية والشفافية الزجاجية من التطبيق:
- حُذفت كل استدعاءات Blur وسياسات التوافق الخاصة بها من كود التطبيق.
- حُذفت خلفية الإضاءة الزخرفية وحدود الزجاج وتعبئته الشفافة.
- استُبدل GlassCard بمكوّن MotionCard ذي خلفية معتمة بنسبة 100% وحد ثابت، بما فيه بطاقات الملفات والمستودعات والمحفوظات والمهام.
- رجعت خلفيات Scaffold وشريطي العنوان والتنقل إلى ألوان ثابتة معتمة.
- بقيت افتتاحية التكبير/الانزلاق والتلاشي القابلة للتخطي، وحركة الضغط وارتداد الأزرار، ورسائل التنبيه المتحركة؛ لا تستخدم ضبابية.
- لا تغيير في الرفع والتنزيل والتوكن المحلي أو وظائف المستودعات. لا تعديلات سحابية.

أضيف اختبار للمصدر يرفض وجود استدعاءات التأثيرات المحذوفة في كود التطبيق، واختبار لعتامة البطاقات، مع الإبقاء على اختبارات التحكم بالحركة والنصوص والنقل.

هذه نسخة Debug. لا يوجد هاتف أو محاكي متصل؛ البناء واختبارات JVM لا تعادل فحصاً بصرياً على هاتف.

## نتيجة البناء
نجح assembleDebug وlintDebug، ونجح 31 اختبار JUnit بلا إخفاقات أو أخطاء، ومنها اختبار إزالة التأثيرات من المصدر وعتامة البطاقات. APK 0.7.0 / versionCode 7، بتوقيع Debug السابق.

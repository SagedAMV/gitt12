# إصدار 0.4.0 — تقرير التحقق

## ما تغيّر
- أربعة تبويبات بدلاً من خمسة، مع إبقاء إدارة السحابة منفصلة.
- تقليل ازدحام رأس شاشة المستودعات وإزالة الشروحات المتكررة.
- إجراءات ورسائل أخطاء قصيرة: «سوّه»، «ارفع ملفات»، «نزّل»، «جرّب ثاني»، «النت مش شغال».
- إنشاء مستودع عام بعد تأكيد المستخدم، باستخدام توكن حساب saged7 فقط.
- رفع ملف حتى **90 MiB = 94,371,840 بايت**. هذا يشمل طلب المستخدم 90 MB العشرية.
- نقل متدفق وإشعار أمامي وتقدم، مع تنظيف الملف المؤقت والتحقق من الحد أثناء القراءة.

## دليل اختبار الحجم
الاختبار `StreamingUploadTest.real90MiBHttpTransfer` ينشئ ملفاً فعلياً على القرص، ثم يستخدم **StreamingUploadBody نفسه الذي يستعمله عميل التطبيق** لإرساله بطلب OkHttp PUT إلى خادم HTTP محلي. يفك الخادم Base64 بالتدفق، ويقارن حجم البايتات وSHA-256 بالمصدر، ويفحص فرع الطلب وعودة HTTP 201، ثم يتحقق الاختبار من اكتمال عداد التقدم.

خرج التشغيل الناجح:

```
Heap limit=67108864; 90 MiB HTTP upload verified: 94371840 bytes; SHA-256 preserved; streamed request bytes=125829200
```

ذاكرة JVM القصوى **64 MiB**، أقل من الملف نفسه، فلا يقتصر الدليل على تغيير ثابت الحد. يشمل النقل تغليف JSON وBase64، وليس مجرد نسخ ملف محلي. حجم الجسم أكبر من الملف بسبب Base64.

اختبارات إضافية:
- ملف 90 MiB + بايت واحد: مرفوض.
- أحجام 0 و1 و2 و3 و65,537 بايت: تطابق Base64 وJSON وطول HTTP وSHA الاختياري، بما يشمل padding.
- اختبارات السياسة وZIP وقصر رسائل الأخطاء: ناجحة.

## نتائج البناء
- 22 اختبار JUnit، صفر إخفاقات، صفر أخطاء.
- assembleDebug: ناجح.
- lintDebug: صفر أخطاء، 14 تحذيراً؛ النجاح لا يعني خلو المشروع من التحذيرات.
- نسخة Android 0.4.0 / versionCode 4، Android 8.0 فما فوق.
- توقيع Debug مطابق لتوقيع APK 0.3.0 السابق، ليس توقيع إصدار إنتاج.

## حدود الإثبات
لم يُرفع الملف إلى GitHub الفعلي، ولم يُنشأ مستودع حقيقي أثناء الاختبار، لعدم وجود توكن مخوّل في جلسة التطوير. الاختبار يثبت مسار جسم طلب الرفع عبر HTTP محلياً على JVM، لا اختبار SAF أو Keystore أو Foreground WorkManager على هاتف. إنشاء المستودع وفحص التوكن ومسار GitHub بحاجة لتجربة المستخدم المخوّل. لا يوجد محاكي/هاتف متصل.

لا تغييرات على Supabase لهذا الإصدار، والتوكن يظل محلياً مشفراً. المسار السحابي القديم ما زال بحدوده السابقة؛ حد 90 MiB الجديد يخص رفع saged7 المباشر.

## إعادة الاختبار
بوجود JDK 17 وAndroid SDK 35 وGradle 8.9:

```
cd android
gradle :app:testDebugUnitTest :app:assembleDebug :app:lintDebug --no-daemon --max-workers=1
```

ضبط `maxHeapSize = "64m"` في Gradle مقصود لإبقاء اختبار النقل منخفض الذاكرة. ملفات الاختبارات المرفقة ضمن docs/test-evidence هي مخرجات التشغيل الفعلي.

- نُشرت الوظائف الإحدى عشرة: auth-login، registration، account، repositories، files، downloads، uploads، admin-users، admin-repositories، admin-items، audit.

- أُنشئ مفتاح publishable عام مخصص لعميل Android باسم android_public.

### GitHub App
لا توجد مفاتيح GitHub App لدى المساعد، ولم يُربط مستودع خاص بعد. يلزم إنشاء/تثبيت GitHub App وضبط هذه الأسرار **داخل Supabase للمشروع الجديد فقط**:
- GITHUB_APP_ID
- GITHUB_INSTALLATION_ID
- GITHUB_OWNER
- GITHUB_PRIVATE_KEY بصيغة PKCS#8

لا تضع private key أو installation token أو service-role key في Android أو في المحادثة. بعد الإعداد، ادخل بالمشرف واربط المستودعات من شاشة الإدارة.

## تنبيهات
- ليس معنى نشر الوظائف أن القراءة والرفع من GitHub يعملان دون GitHub App.
- حد الرفع المؤقت 8 MiB، وليس 90 MB. لا يزال اختبار النقل والحمل مطلوباً.
- قاعدة البيانات أُنشئت بكلمة مرور عشوائية غير مدرجة في الملفات؛ يمكن للمالك تدويرها من لوحة Supabase عند الحاجة.
- APK إصدار تطوير موقّع Debug، وليس نسخة متجر.

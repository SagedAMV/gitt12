# إصدار 0.5.0 — النصوص ورسائل الحركة

## نطاق المراجعة
فُحصت جميع ملفات Kotlin وXML داخل Android main: **61 ملفاً**. بعد التعديل سجّل الفحص **425 موضعاً عربياً، و293 نصاً فريداً** (يشمل ثوابت القوالب وسياسة الرسائل)، بلا نص عربي ثابت يتجاوز ثلاث كلمات. تشمل المراجعة شاشات GitHub والدخول والملفات المحلية والمهام والإدارة والمستخدمين والسجل والإعدادات، ونصوص الشبكة والتحويل والإشعارات.

- سُجّلت 142 عملية استبدال مباشرة في COPY_CHANGES_0.5.0.json، إضافة إلى إعادة صياغة القوالب المركبة يدوياً.
- التقرير القابل للفحص: UI_COPY_AUDIT_0.5.0.json.
- `python scripts/audit-ui-copy.py` يعيد الفحص ويخرج بحالة فشل عند التجاوز.
- أضيف CopySourceTest إلى اختبارات Gradle لمنع عودة النصوص العربية الطويلة.
- فُحصت النصوص الإنجليزية الطويلة أيضاً: تخص SQL ورسائل ZIP الداخلية ورسالة commit؛ ليست عناوين واجهة. رسائل ZIP التي تصل للمستخدم تُحوّل إلى نص عربي معتمد.
- أسماء الملفات والمجلدات والفروع والمستخدمين، المسارات، الوقت، قيم سجل التدقيق، ومحتوى المعاينة **بيانات وليست تسميات**؛ لا تُقصّر أو تتغير في المصدر. تُعرض بعض البيانات في سطر محدود بصرياً. أزيل وصف المستودع الطويل من بطاقة القائمة.

## الرسائل المتحركة
المكوّن MotionNotice موحّد بين شاشة GitHub ورسائل التطبيق العامة وأخطاء المهام:
- دخول بتلاشي وانزلاق وتمدد، وخروج بتلاشي وانكماش.
- نبضة دائرية مرسومة بـCanvas مع تكبير ناعم للرمز، مدتها 720ms وغير متكررة.
- ألوان وأيقونات مختلفة للنجاح والتنبيه والخطأ، مع احترام الثيم الفاتح والغامق.
- عنوان لا يتجاوز ثلاث كلمات، وتوجيه مستقل لا يتجاوز ثلاث كلمات.
- رقم مرجعي قصير للأخطاء فقط، من E00 إلى E14، للمساعدة في وصف المشكلة.
- لا تختفي الرسالة بمؤقت؛ تُغلق بضغط «تمام». إشعارات القراءة المساعدة LiveRegion.Polite موجودة.
- لا يُعرض نص خطأ الخادم الخام أو stack trace؛ العناوين من قائمة معتمدة، وليس اقتطاع كلمات من رسالة تقنية.

أمثلة:

| الحالة | العنوان | التوجيه |
|---|---|---|
| E01 | النت مش شغال | شيّك النت |
| E02 | التوكن مش شغال | حط توكن جديد |
| E03 | ما معك صلاحية | راجع صلاحية التوكن |
| E05 | الملف فوق الحد | اختار ملف أصغر |
| E06 | الملف اتغيّر | حدّث وجرّب ثاني |
| E12 | حسابك مش مفعّل | كلّم المشرف |

## التحقق الفعلي
- نجح البناء assembleDebug وlintDebug.
- **27 اختباراً**: 10 ZIP، و8 سياسة GitHub، و3 نقل متدفق، و5 رسائل ومرجعيات، واختبار شامل للنصوص بالمصدر؛ صفر إخفاقات وأخطاء.
- أعيد اختبار نقل ملف 90 MiB عبر HTTP محلي بذاكرة JVM قصوى 64 MiB؛ نجح حفظ SHA-256.
- Lint: صفر أخطاء و14 تحذيراً. لا يعد النجاح تصديقاً للإنتاج.
- نسخة 0.5.0، versionCode 5، توقيع Android Debug مطابق للنسخ السابقة.
- النتائج الأصلية مرفقة في test-evidence/0.5.0.

# GitHub Vault — Android 0.3.0

## الجديد: قراءة حساب saged7 دون توكن
تفتح النسخة 0.3.0 على مستودعات **saged7 العامة** دون تسجيل دخول أو إعداد GitHub App. تتضمن تصفح المجلدات ومعاينة نصية وتنزيل ملفات، وخانة **توكن الرفع** الاختيارية. يحفظ التوكن مشفراً على الهاتف ويرسل إلى GitHub مباشرة، ولا يرسل إلى Supabase. [دليل هذا الوضع وحدوده](docs/SAGED7_PUBLIC_MODE.md).

المسار السابق للسحابة وإدارة المستخدمين يبقى متاحاً من تبويب المستودعات/الإدارة، ولا يلزم استخدامه للتصفح العام. تعليمات GitHub App أدناه تخص المسار القديم فقط؛ لا تحتاجه لقراءة saged7 أو للرفع المباشر بالتوكن.


تطبيق Android أصلي بـ Kotlin وJetpack Compose، مع واجهة عربية RTL، وSupabase كطبقة المصادقة والتفويض، وGitHub App لحفظ الملفات في المستودعات الخاصة.

**الحالة:** نسخة تطوير مبنية ومربوطة بمشروع Supabase مستقل جديد باسم `github-vault`، وليست اعتماداً للإنتاج. نُشرت وظائفها وجداولها؛ أُنشئ حساب المشرف وفُحص دخوله وصلاحياته؛ ما زال GitHub App بحاجة إلى إعداد. راجع [حالة التنفيذ والاختبار](docs/IMPLEMENTATION_STATUS.md).

## الميزات المكتوبة
- دخول باسم المستخدم، طلب تسجيل، موافقة/رفض المشرف، تغيير كلمة المرور وإلزام أصحاب الكلمات المؤقتة بتغييرها.
- جلسات مشفرة بـ Android Keystore وAES-GCM، وتجديد الجلسات وتسجيل خروج خادمي.
- عرض المستودعات المخصصة، تصفح المجلدات، بحث وتحديد متعدد، تنزيل ملف أو ZIP لمجموعة أو مجلد.
- رفع ملفات متعددة ومجلدات عبر SAF، وتمثيل المجلد الفارغ بـ `.gitkeep`.
- إنشاء مجلد، ونقل/إعادة تسمية/حذف الملفات والمجلدات عبر commits دون force push.
- WorkManager للمهام، تقدم وحالة مستقلة، إلغاء وإعادة محاولة.
- حفظ محلي وفهرسة Room، تصفح وبحث وفتح عبر FileProvider دون اتصال، وفحص نسخ أحدث دون استبدال تلقائي.
- إدارة المستخدمين والمستودعات والصلاحيات وسجل النشاط بالبحث والفلاتر والصفحات.
- تصميم فاتح/داكن، حركات انتقال وتقدم وواجهة عربية مع نوافذ تأكيد.
- 11 Edge Function وهجرتان SQL مطابقـتان لسجل المشروع الجديد مع RLS واختبارات رفض التفويض.

## تجربة APK
1. ثبّت APK التجريبي على جهاز Android 8.0 أو أحدث.
2. الاتصال بالمشروع الجديد مضمن مسبقاً في النسخة 0.2.1؛ لا تحتاج إدخاله يدوياً.
3. تحتوي `android/vault-project.properties` على URL والمفتاح العام فقط؛ لا توجد مفاتيح إدارية. تغيير الاتصال إلى مشروع آخر مرفوض في هذه النسخة.
4. حساب المشرف جاهز، والدخول في التطبيق باسم `sagedkhan746`. يلزم تهيئة GitHub App قبل تشغيل الملفات الخاصة. الهجرات والوظائف نُشرت بالفعل.
5. الملفات المحلية متاحة من شاشة الدخول حتى بعد تسجيل الخروج.

## البناء من المصدر
- JDK 17، Android SDK 35، Gradle Wrapper 8.9 المرفق.
- افتح `android/` في Android Studio، واضبط مسار SDK المحلي المعتاد.
- إعداد الاتصال العام مثبت في `android/vault-project.properties` ويُقرأ أثناء البناء. لا تستخدم local.properties لتغيير المشروع؛ يخصص لمسار SDK فقط.

```bash
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug --no-daemon
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

نسخة Debug موقعة بمفتاح التطوير، وليست حزمة متجر. مفتاح توقيع الإنتاج وتهيئة التوزيع ملك للمستخدم ولا تُولّد أسرار إنتاج داخل المستودع.

## الفحوصات
```bash
# Node 22 وDeno 2
npm ci --ignore-scripts
npm run test:db
deno task check
deno task test
```

اختبارات SQL تعمل على PostgreSQL مضمّن عبر PGlite مع بيئة Auth محاكاة، وليست اتصالاً بمشروع Supabase الحقيقي. اختبارات HTTP للتفويض تحاكي Auth/PostgREST ولا تنقل ملفات حقيقية إلى GitHub.

## حدود يجب معرفتها
- **رفع الملف: 8 MiB مؤقتاً، وليس 90 MB.** رفع 90 MB يحتاج مسار نقل واختبار حمل قبل اعتماده.
- ZIP: 1000 ملف و200 MiB غير مضغوط. ZIP يولد بالتدفق دون ضغط، مع الحفاظ على المسارات من جذر المستودع.
- ملفات التنزيل المفردة حتى 90 MiB في فحص الكود فقط؛ النقل الفعلي عند هذا الحجم غير معتمد بعد.
- مجموعة رفع: 1000 عنصر و200 MiB وفق الأحجام المعلنة من موفر Android، مع إعادة التحقق من حجم كل ملف فعلياً عند الإرسال.
- الشجرة حتى 10,000 مدخل. ملفات symlink غير قابلة للتنزيل. المستودع الجديد الفارغ يحتاج commit أولياً في GitHub.
- قائمة إدارة المستخدمين تعرض حتى 500 حساب. اكتشاف GitHub يعرض أول 100 مستودع، ويمكن ربط أي مستودع آخر بالاسم.
- لا تُحذف النسخ المحلية عند سحب الصلاحيات. حذف التطبيق قد يحذفها.

لا تنشر التغييرات على مشروع Supabase موجود قبل التأكد أنه المشروع الصحيح وأخذ نسخة احتياطية.
